# Food.io - Modern Restaurant Web Application

Food.io, modern UI/UX standartlarına göre tasarlanmış ve interaktif JavaScript özellikleriyle zenginleştirilmiş bir restoran web uygulamasıdır. Yalnızca statik bir tasarım değil; dinamik sepet yönetimi, tema geçişleri ve anlık bildirim sistemleriyle tam teşekküllü bir Front-End (Web App) projesidir.

## ✨ Öne Çıkan Özellikler

* 🌗 **Dark / Light Mode:** JavaScript ile kontrol edilen, sayfanın tüm renk paletini yumuşak bir animasyonla değiştiren karanlık tema entegrasyonu.
* 🛒 **Dinamik Sepet Sistemi:** Ürünlerin eklenebildiği, çıkarılabildiği ve toplam tutarın otomatik hesaplandığı sağdan kayarak açılan sepet çekmecesi (Sidebar Cart).
* 🔔 **Toast Bildirimleri (Custom Alerts):** Tarayıcının varsayılan sıkıcı uyarıları yerine, ekranın sağ altından süzülerek gelen ve 3 saniye sonra kaybolan modern kullanıcı bildirimleri.
* 🔍 **Kategori Filtreleme:** Menüdeki yemekleri kategorilerine göre (Vegan, Salmon, Chicken vb.) anında filtreleyen ve DOM'u güncelleyen etkileşimli sekme yapısı.
* 📱 **Tam Mobil Uyumluluk (Responsive):** CSS Grid ve Flexbox kullanılarak her ekran boyutuna adapte olan tasarım ve mobil cihazlar için özel Hamburger Menü.
* ✨ **Scroll Reveal Animasyonları:** `IntersectionObserver` API kullanılarak sayfa aşağı kaydırıldıkça yumuşakça beliren içerik kutuları.

## 🛠 Kullanılan Teknolojiler

* **HTML5:** Semantik web standartları (Section, Footer, Nav).
* **CSS3:** Flexbox, CSS Grid, Custom Keyframe animasyonları, Hover efektleri ve Medya Sorguları (Media Queries).
* **JavaScript:** DOM Manipülasyonu, Event Listener'lar, Array/Object yönetimi, Intersection Observer API.
* **Boxicons:** Vektörel ikon seti.
